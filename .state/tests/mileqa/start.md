# mileqa reports

Reports from /mileqa runs (pre-milestone holistic QA). One subdirectory per run, named YYYYMMDD-HHMM (run start). Run subdirectories are report data — rounds, verified findings, fix records, and a summary.md with the exit state — and do not carry their own start.md. Signal prefixes: see ^/.state/start.md.
