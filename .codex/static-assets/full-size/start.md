# full-size

Large-format Rooted Hex exports for repository and social headers — 2:1 aspect, the
mark centred on a field. See `../start.md` for the light/dark convention.

## What's here

| File | Size | Field |
|---|---|---|
| `claudette-1280x640.png` | 1280×640 | light — recommended GitHub display size |
| `claudette-640x320.png` | 640×320 | light — minimum GitHub target |
| `claudette-dark-1280x640.png` | 1280×640 | dark `#0B0F14` |
| `claudette-dark-640x320.png` | 640×320 | dark `#0B0F14` |

Masters live in `../icons/` (`claudette.svg`, `claudette-dark.svg`). Re-export from
there; don't hand-edit these rasters.
