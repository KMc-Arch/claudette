# overrides

Our conventions, layered over the vendored skills. They win over `SKILL.md`; governance wins over both.

- [common.md](common.md): applies to every skill; read first, always.
- [wayfinder.md](wayfinder.md): tracker operations for maps and tickets, the labelled operator prompts, and the session read-out.
- [domain-modeling.md](domain-modeling.md): where the glossary and decisions live.
- [git-guardrails-claude-code.md](git-guardrails-claude-code.md): project-only install, registered in local settings.
- [claude-handoff.md](claude-handoff.md): blocked until reviewed.
- [chief-of-staff.md](chief-of-staff.md): blocked until reviewed (experimental upstream).

Add a file here when a skill's defaults collide with how we work. Don't copy upstream text; state only the delta.
